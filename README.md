## 言語ギャップ・翻訳不可能語クイズ

世界各国の「他の言語に翻訳できない感情・概念を表す単語」を4択クイズ形式で学ぶ文化探求クイズ。

### 機能
- 30語以上の翻訳不可能語データ（言語・単語・意味・文化背景・使用例・4択選択肢）
- 4択クイズUI（正解発表アニメーション付き）
- 正解後の文化的背景・使用例解説カード
- 10問1セット形式・スコア表示
- 難易度（全言語ランダム / アジア語圏 / ヨーロッパ語圏 / 感情・心理系）
- localStorage: ハイスコア・既出問題管理（重複排除）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- localStorage永続化（モード別ハイスコア・出題済み単語管理）
- CSS keyframesアニメーション（shake・reveal）
